What is Meto Live App?

Meto Live is a social live-streaming app where users can watch live content, chat, video calls, send gifts, and connect with hosts. The platform has two earning paths: Hosts create and interact with viewers, while Agents build and manage the team of Hosts.

How to Register as a Meto Agent

You create an account first, copy your Meto ID, then use that ID to complete the agency verification process.

  1. Download the Meto Live App

    Install the app from the official download link and open it on your phone.

  2. Create Your Account

    Sign up using an available option such as email, phone number, or Google.

  3. Copy Your Meto ID

    Open your profile and copy the account ID shown in the app.

  4. Open the Agency Registration Form

    Go to the Meto agency registration link right here.

  5. Paste Your Meto ID & Get Verification Code

    Enter the ID in the form and tap Get to request a verification code.

  6. Verify and Submit

    Enter the verification code, then click Submit. After submitting the code, you will be redirected to the Meto Live Agent Dashboard.

Frequently Asked Questions

What is a Meto Agent?

A Meto Agent is an agency partner who recruits and supports Hosts and Sub-Agents inside the Meto Live App and can earn from eligible agency activity.

How do I become a Meto Agent?

Create a Meto Live account, copy your Meto ID, open the agency registration form, request the verification code, enter the code, and submit the registration.

Do I need the Meto Live App before agency registration?

Yes. You need a Meto account and Meto ID before you can complete the agency registration form.

Can a Meto Agent invite both Hosts and Sub-Agents?

Yes. The current Agent tools include separate invitation options for Hosts and Sub-Agents.

How does a Meto Agent earn?

Eligible Agent earnings can come from agency commission and invitation rewards. Commission is tied to qualifying agency activity under the current program rules.

Does a Meto Agent need to livestream?

The Agent role is centered on recruiting, managing, and supporting a team. You do not need to make personal livestreaming the main activity of the agency role.

How do I add a Host to my Meto agency?

Open the Meto Live App, go to Profile > Agent > Invite Host, copy the official invitation link, and send it to the Host you want to recruit.

What is the difference between a Meto Host and a Meto Agent?

A Host earns mainly through personal host activity. A Meto Agent focuses on building and supporting a team and can earn from eligible agency activity.

Can anyone become a Meto Host?

Yes, but Hosts still must meet the current requirements, including the 18+ rule and account authentication. Some accounts may also need a livestreaming trial/audition before being able to freely livestream on their own..

Can earnings or program rules change?

Yes. Commission, rewards, Host bonuses, withdrawal methods, and eligibility can vary by country, account status, performance, and the latest Meto Live policy.
